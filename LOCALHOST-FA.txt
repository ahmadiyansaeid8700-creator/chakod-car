اجرای نسخه حرفه‌ای صفحه اصلی چاکود روی لوکال‌هاست

1) اگر سرور قبلی باز است، در ترمینال Ctrl + C بزنید.
2) محتویات این پوشه را داخل پوشه فعلی chakod-car کپی و Replace کنید.
3) فایل .env.local فعلی را حذف نکنید. این فایل داخل بسته وجود ندارد.
4) داخل پوشه chakod-car این دستورها را اجرا کنید:

npm.cmd install
npm.cmd run dev

5) سپس این آدرس را باز کنید:

http://localhost:3000

فعلاً چیزی روی هاست منتشر نکنید. بعد از تأیید ظاهر موبایل و دسکتاپ،
نسخه نهایی برای انتشار آماده می‌شود.
