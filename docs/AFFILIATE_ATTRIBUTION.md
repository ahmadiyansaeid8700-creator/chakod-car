# Chakod — Affiliate Attribution Model

Status: SUPERSEDED / DO NOT IMPLEMENT FOR V1

مدل لینک اختصاصی Affiliate، کمیسیون فروش و Attribution حرفه‌ای برای نسخه اول کنار گذاشته شد.

مرجع فعلی محصول:

`docs/REFERRAL_REWARDS.md`

در نسخه اول:
- هر کاربر یک کد دعوت/تخفیف اختصاصی دارد.
- کاربر جدید با کد، مزیت خوش‌آمدگویی می‌گیرد.
- معرف فقط پس از اولین خرید موفق کاربر جدید پاداش می‌گیرد.
- پاداش معرف اعتبار چاکود/تخفیف خرید بعدی است.
- کلیک، بازدید و Referral Link مستقل منبع پاداش نیستند.

اگر در آینده Attribution مبتنی بر لینک یا Affiliate حرفه‌ای لازم شد، این سند باید با تصمیم محصول جدید بازطراحی شود.
