# چک‌لیست دستیار هوش مصنوعی مستقل چاکود

> این سند بخش رسمی چک‌لیست توسعه چاکود است و برای ساخت یک دستیار کاربردی، فارسی و کارراه‌انداز استفاده می‌شود. هسته اصلی دستیار باید بدون وابستگی اجباری به APIهای هوش مصنوعی بیرونی کار کند.

## هدف

دستیار باید کاربر را در انجام کارهای واقعی سایت راهنمایی کند؛ نه اینکه فقط یک چت نمایشی باشد. در صورت قطع سرویس‌های بیرونی، قابلیت‌های اصلی راهنمایی، جست‌وجو، مسیریابی و پاسخ‌های ثابت همچنان باید فعال بمانند.

## ۱. تعریف دامنه و معماری

- [ ] تعریف دقیق کارهایی که دستیار مجاز است انجام دهد.
- [ ] جداسازی قابلیت‌های مستقل از قابلیت‌های نیازمند مدل زبانی.
- [ ] طراحی هسته Rule-based برای اجرای دستورات و پیشنهاد مسیرها.
- [ ] طراحی پایگاه دانش داخلی فارسی برای سؤالات پرتکرار.
- [ ] تعریف قرارداد مشترک Intent، Action و Response.
- [ ] جلوگیری از وابستگی اجباری سایت به OpenAI یا سرویس مشابه.
- [ ] امکان افزودن مدل محلی یا API بیرونی به‌عنوان قابلیت اختیاری.

## ۲. قابلیت‌های کارراه‌انداز کاربر

- [ ] راهنمای جست‌وجو و فیلتر خودرو براساس بودجه، شهر، برند و کارکرد.
- [ ] هدایت مستقیم کاربر به مسیر مناسب سایت.
- [ ] راهنمای مرحله‌به‌مرحله ثبت آگهی.
- [ ] راهنمای تکمیل پروفایل شخصی یا تجاری.
- [ ] راهنمای ثبت نمایشگاه، تعمیرگاه، مرکز خدمات و فروشگاه قطعات.
- [ ] توضیح وضعیت آگهی، ردشدن، انقضا و اقدامات بعدی.
- [ ] توضیح ساده خطاهای فرم و پیشنهاد راه‌حل.
- [ ] معرفی خدمات مرتبط بدون ساختن اطلاعات یا قیمت جعلی.
- [ ] پاسخ به پرسش‌های پرتکرار قوانین، پرداخت، حساب و پشتیبانی.
- [ ] پیشنهاد دکمه و اقدام بعدی در همان پاسخ.

## ۳. تجربه کاربری

- [ ] رابط فارسی و RTL.
- [ ] نمایش در دسکتاپ و موبایل بدون پوشاندن محتوای اصلی.
- [ ] باز و بسته‌شدن سریع و حفظ وضعیت گفتگو در همان نشست.
- [ ] نمایش پاسخ‌های کوتاه و قابل انجام.
- [ ] ارائه دکمه‌های عملی مانند «رفتن به ثبت آگهی» یا «نمایش خودروها».
- [ ] امکان شروع دوباره گفتگو.
- [ ] امکان گزارش پاسخ نامناسب.
- [ ] رعایت دسترس‌پذیری کیبورد و Screen Reader.

## ۴. حالت مستقل و آفلاین

- [ ] نگهداری Intentهای اصلی و پاسخ‌های ضروری داخل پروژه.
- [ ] کارکرد راهنمای مسیرها هنگام قطع API هوش مصنوعی.
- [ ] کارکرد سؤالات پرتکرار هنگام قطع اینترنت یا سرویس بیرونی.
- [ ] نمایش شفاف محدودیت‌ها در حالت آفلاین.
- [ ] جلوگیری از توقف یا کندشدن سایت در صورت خرابی دستیار.
- [ ] بارگذاری تنبل دستیار برای کاهش حجم اولیه صفحه.
- [ ] Cache نسخه‌ای پایگاه دانش در مرورگر.

## ۵. دانش و مدیریت محتوا

- [ ] ساخت پایگاه دانش نسخه‌بندی‌شده.
- [ ] ثبت منبع و تاریخ آخرین ویرایش هر پاسخ حساس.
- [ ] امکان ویرایش پاسخ‌ها توسط مدیر مجاز.
- [ ] تفکیک پاسخ‌های عمومی، مالی، حقوقی و امنیتی.
- [ ] جلوگیری از نمایش اطلاعات منقضی یا تأییدنشده.
- [ ] تعریف پاسخ جایگزین برای سؤال خارج از دامنه.
- [ ] هدایت به پشتیبانی انسانی وقتی پاسخ قطعی وجود ندارد.

## ۶. امنیت و حریم خصوصی

- [ ] عدم دریافت یا نمایش رمز عبور، کد پیامکی، Token و اطلاعات کارت.
- [ ] عدم اجرای پرداخت، حذف، تغییر مالکیت یا عملیات حساس بدون تأیید صریح کاربر.
- [ ] عدم نمایش اطلاعات حساب یا آگهی بدون احراز هویت معتبر.
- [ ] پاک‌سازی ورودی‌ها برای جلوگیری از XSS و Prompt Injection.
- [ ] محدودیت طول و نرخ پیام‌ها.
- [ ] عدم ارسال خودکار متن گفتگو به سرویس خارجی.
- [ ] رضایت شفاف کاربر پیش از استفاده از مدل ابری اختیاری.
- [ ] ثبت لاگ حداقلی و بدون اطلاعات حساس.

## ۷. صحت پاسخ و کنترل خطا

- [ ] ممنوعیت ساخت قیمت، موجودی، وضعیت آگهی یا اطلاعات کسب‌وکار.
- [ ] دریافت داده‌های زنده فقط از APIهای رسمی چاکود.
- [ ] اعلام واضح ناتوانی در پاسخ قطعی.
- [ ] نمایش پیام مناسب هنگام قطع API سایت.
- [ ] جلوگیری از پیشنهاد مسیر ناموجود.
- [ ] تست تمام لینک‌ها و Actionهای پیشنهادی دستیار.

## ۸. پنل مدیریت و تحلیل

- [ ] مشاهده سؤالات پرتکرار بدون ذخیره اطلاعات حساس.
- [ ] مشاهده Intentهای ناموفق.
- [ ] افزودن و ویرایش پاسخ‌های پایگاه دانش.
- [ ] فعال یا غیرفعال‌کردن قابلیت مدل ابری.
- [ ] تعیین سطح دسترسی مدیران دستیار.
- [ ] ثبت لاگ تغییرات پایگاه دانش.
- [ ] گزارش میزان حل مسئله و انتقال به پشتیبانی.

## ۹. تست و انتشار

- [ ] تست بدون اتصال به سرویس هوش مصنوعی بیرونی.
- [ ] تست قطع APIهای چاکود.
- [ ] تست موبایل و دسکتاپ.
- [ ] تست اینترنت ضعیف.
- [ ] تست کاربر مهمان و واردشده.
- [ ] تست نقش‌های شخصی و تجاری.
- [ ] تست امنیت، حریم خصوصی و ورودی مخرب.
- [ ] تست عدم ایجاد بن‌بست در گفتگو.
- [ ] تست Performance و حجم Bundle.
- [ ] انتشار مرحله‌ای و امکان غیرفعال‌سازی فوری.

## شرط پایان

دستیار بدون وابستگی اجباری به سرویس بیرونی، کاربر را تا رسیدن به یک اقدام واقعی در سایت هدایت کند؛ اطلاعات جعلی تولید نکند، عملیات حساس را بدون تأیید انجام ندهد و در صورت ناتوانی کاربر را به مسیر یا پشتیبانی مناسب منتقل کند.
