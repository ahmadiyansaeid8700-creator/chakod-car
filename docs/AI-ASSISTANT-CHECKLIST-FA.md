# چک‌لیست دستیار هوش مصنوعی مستقل چاکود

> این سند بخش رسمی چک‌لیست توسعه چاکود است و برای ساخت یک دستیار کاربردی، فارسی و کارراه‌انداز استفاده می‌شود. هسته اصلی دستیار باید بدون وابستگی اجباری به APIهای هوش مصنوعی بیرونی کار کند.

## هدف

دستیار باید کاربر را در انجام کارهای واقعی سایت راهنمایی کند؛ نه اینکه فقط یک چت نمایشی باشد. در صورت قطع سرویس‌های بیرونی، قابلیت‌های اصلی راهنمایی، جست‌وجو، مسیریابی و پاسخ‌های ثابت همچنان باید فعال بمانند.
