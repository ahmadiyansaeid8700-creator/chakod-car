# تصمیم‌های تاییدشده لانچ چاکود

این فایل مرجع تصمیم‌هایی است که مالک پروژه صریحا تایید کرده است. هر مورد تاییدشده باید در این فایل ثبت شود تا در ادامه پروژه دوباره بازطراحی یا تغییر داده نشود، مگر با تایید صریح جدید مالک.

## قاعده ثبت

- هر تصمیم تاییدشده با وضعیت `[x]` ثبت می‌شود.
- موارد در حال بررسی با `[~]` ثبت می‌شوند.
- تغییر تصمیم تاییدشده فقط با تایید صریح جدید مالک انجام می‌شود.
- پیاده‌سازی هر تصمیم باید روی شاخه Staging انجام و قبل از انتقال به Production تست شود.

## تصمیم‌های تاییدشده تا ۱۸ مرداد ۱۴۰۵

### ورود و خوش‌آمدگویی

- [x] صفحه خوش‌آمدگویی بعد از ورود از تصویر تاییدشده چاکود با BMW سفید، نورپردازی بنفش و لوگوی رسمی چاکود استفاده کند.
- [x] متن خوش‌آمدگویی: «به چاکود خوش آمدید» و زیرمتن «در حال ورود به صفحه اصلی...».
- [x] مدت نمایش اسپلش حدود ۲.۶ ثانیه باشد.
- [x] بعد از اسپلش انتقال با `replace` انجام شود تا با Back دوباره اسپلش ظاهر نشود.
- [x] برای اینترنت ضعیف، بعدا fallback حداکثر زمان انتظار در مرحله Performance اضافه شود.

### کمپین افتتاحیه

- [x] کد افتتاحیه `GOLSHAN` برای سفارش‌های واجد شرایط مبلغ همان خرید را صفر می‌کند.
- [x] فقط خدمت خریداری‌شده رایگان می‌شود، نه کل خدمات حساب.
- [x] مدت خدمت هدیه حداکثر ۴۵ روز از زمان فعال‌سازی است.
- [x] هدیه نقدی نیست و قابل تبدیل یا برداشت به وجه نیست.
- [x] تمدید خودکار پولی برای این هدیه انجام نمی‌شود.

### قوانین و انطباق

- [x] قوانین اصلی، شرایط استفاده، حریم خصوصی، سیاست بازپرداخت و اطلاعات حقوقی به نسخه ۱.۲ ارتقا یافتند.
- [x] پذیرش قوانین به شماره موبایل و OTP متصل و نسخه اسناد ثبت می‌شود.
- [x] چارچوب فعالیت چاکود بر اساس رسته «بستر آنلاین کاربرمحور نیازمندی‌ها» با کد آیسیک 521126 در نظر گرفته شده است.
- [x] مسئولیت محتوای آگهی با آگهی‌دهنده است و مسئولیت‌های قانونی مستقیم چاکود ساقط نمی‌شوند.
- [x] الزامات نگهداری IP، شکایت و گزارش تخلف، کنترل قیمت در شرایط اعلامی و نگهداری داده داخل کشور در قوانین لحاظ شده‌اند.

### زیرساخت Production

- [x] توسعه و Staging فعلا روی Cloudflare ادامه پیدا کند.
- [x] بعد از نهایی شدن سایت، برای Production یک VPS با لوکیشن فیزیکی داخل ایران از میهن وب هاست یا سرویس معادل تهیه شود.
- [x] اطلاعات واقعی کاربران، آگهی‌ها، پرداخت‌ها، پذیرش قوانین، IPها، تیکت‌ها و داده‌های عملیاتی Production روی زیرساخت داخل ایران نگهداری شوند.
- [x] Cloudflare D1 فعلی برای Staging/توسعه بماند و مخزن نهایی داده واقعی کاربران Production نباشد.
- [~] پیش از خرید VPS، محل فیزیکی سرور و محل نگهداری Backup به صورت کتبی از سرویس‌دهنده تایید شود.
- [~] مهاجرت Production شامل DB، فایل‌ها، لاگ IP، پذیرش قوانین، Backup/Restore و تست امنیت به صورت فاز مستقل انجام شود.

## اصل ثابت ادامه پروژه

از این تاریخ هر چیزی که مالک پروژه تایید می‌کند باید هم در کد/تنظیمات مربوط اجرا شود و هم در همین فایل ثبت شود تا به عنوان تصمیم مرجع پروژه باقی بماند.
