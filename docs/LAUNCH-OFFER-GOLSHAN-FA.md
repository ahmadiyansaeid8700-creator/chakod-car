# کمپین افتتاحیه چاکود — GOLSHAN

## تصمیم محصول

این کمپین برای روزهای آغازین فعالیت چاکود طراحی شده است تا کاربران بتوانند بدون پرداخت واقعی، یک سرویس مدت‌دار را تجربه کنند و ریسک خطاهای اولیه لانچ کاهش پیدا کند.

## قواعد نهایی کمپین

- کد کمپین: `GOLSHAN`
- تخفیف: 100٪
- مبلغ پرداختی سفارش مشمول: 0 تومان
- کاربر باید سرویس یا محصول را خودش انتخاب کند.
- هیچ سرویس یا محصولی به‌صورت خودکار برای کاربر فعال نمی‌شود.
- فقط همان محصول یا سرویس انتخاب‌شده مشمول هدیه می‌شود.
- مدت فعال بودن سرویس کمپینی: 45 روز از زمان فعال‌سازی.
- پس از پایان 45 روز، سرویس به‌صورت خودکار منقضی می‌شود.
- برای ادامه استفاده پس از انقضا، خرید عادی لازم است.
- سفارش صفر تومانی نباید به زرین‌پال ارسال شود.
- در فاکتور باید قیمت اصلی، تخفیف GOLSHAN و مبلغ نهایی صفر تومان ثبت و نمایش داده شود.
- زمان شروع و پایان باید به‌صورت واقعی در داده سفارش/اشتراک ذخیره شود.
- در حساب کاربر بهتر است وضعیت هدیه و تعداد روز باقی‌مانده نمایش داده شود.

## محصولات مناسب کمپین

این مدل برای سرویس‌های مدت‌دار مناسب است، از جمله:

- اشتراک‌های حرفه‌ای
- آگهی ویژه مدت‌دار
- جایگاه ویژه نمایشگاه
- جایگاه ویژه کسب‌وکار
- سایر سرویس‌های مدت‌دار که در زمان لانچ تعیین می‌شوند

## محصولات یک‌بارمصرف

محصولاتی مانند «بالابر آگهی» ذاتاً یک‌بارمصرف هستند و مفهوم فعال بودن 45 روزه برای آن‌ها مناسب نیست. این محصولات باید یا از کمپین خارج شوند یا در آینده قانون مستقل و صریح برای آن‌ها تعریف شود.

## الزامات پیاده‌سازی

- اعتبارسنجی کد باید سمت سرور انجام شود.
- تخفیف و مدت کمپین نباید صرفاً در JavaScript مرورگر تعیین شوند.
- استفاده از کد باید در دیتابیس ثبت شود.
- مدیر سایت باید بتواند کمپین را فعال یا غیرفعال کند.
- محصولات مشمول کمپین باید قابل‌کنترل باشند.
- اگر مبلغ نهایی صفر شد، مسیر پرداخت باید بدون ورود به زرین‌پال سفارش را تکمیل کند.
- فعال‌سازی سرویس باید idempotent باشد تا Refresh یا درخواست تکراری باعث فعال‌سازی دوباره نشود.
