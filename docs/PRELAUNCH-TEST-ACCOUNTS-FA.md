# حساب‌های تست پیش از افتتاح

این بسته فقط تعریف حساب‌ها و تصاویر کم‌حجم را اضافه می‌کند و به‌صورت پیش‌فرض غیرفعال است.

## قواعد ایمنی

- حساب تست فقط با پیشوند `TEST_` ساخته می‌شود.
- همه رکوردها باید به Batch برابر `prelaunch_2026` متصل شوند.
- Seed روی محیط Production ممنوع است.
- شماره موبایل واقعی یا OTP واقعی داخل Git ذخیره نمی‌شود.
- حذف نهایی فقط با تطبیق هم‌زمان پیشوند و Batch انجام می‌شود.
- اسکریپت ساخت و پاک‌سازی بعد از نهایی‌شدن Schema واحد MySQL اضافه می‌شود.

## نقش‌های اولیه

- کاربر شخصی
- نمایشگاه‌دار
- فروشگاه قطعات
- تعمیرگاه
- خدمات خودرو
- مدیر محدود
- پشتیبان
- ناظر محتوا

## تصاویر

تصاویر مسیر `public/test-avatars/` ساختگی هستند، به شخص واقعی تعلق ندارند و برای نمایش آزمایشی پنل‌ها استفاده می‌شوند. هر فایل WebP ابعاد ۲۵۶×۲۵۶ و حجم تقریبی ۵ تا ۷ کیلوبایت دارد.

## وضعیت

`test-fixtures/prelaunch-accounts.json` عمداً `enabled: false` است. تا پیش از تثبیت MySQL و محیط آزمایشی، هیچ حساب یا رکورد دیتابیسی ساخته نمی‌شود.
