# وضعیت پروژه چاکود

آخرین بروزرسانی: شروع توسعه سیستم فرصت طلایی

## انجام شده

- ایجاد ساختار اصلی پروژه Next.js
- صفحات اصلی سایت
- سیستم نمایش آگهی‌ها
- سیستم لوکیشن و نمایش آگهی‌های منطقه‌ای
- حساب کاربری کاربران
- بخش نمایشگاه‌ها
- پنل مدیریت
- زیرساخت API
- ایجاد مستندات سیستم فرصت طلایی

## تکمیل و بررسی‌های اخیر

- طراحی مفهوم قوانین و قیمت‌های مرکزی
- تصمیم‌گیری برای مدیریت تنظیمات تجاری از پنل

## در حال انجام

### سیستم فرصت طلایی

هدف:
ایجاد مسیر رزرو و نمایش ویژه آگهی‌های جذاب با بررسی هوش مصنوعی.

مراحل:

1. تنظیمات مرکزی فرصت طلایی
2. پنل مدیریت قوانین و قیمت‌ها
3. مسیر کاربر شخصی و نمایشگاه
4. پرداخت هزینه بررسی
5. بررسی هوش مصنوعی
6. پیام داخلی تایید یا رد
7. بازگشت وجه در صورت رد
8. نمایش در صفحه اصلی

## موارد باقی مانده

- حذف کامل منطق کارت روز قدیمی
- جایگزینی فضای کارت روز با ویترین فرصت طلایی
- اتصال تمام مسیرهای خرید به تنظیمات مرکزی
- تکمیل گزارش‌ها و مدیریت‌ها

## قوانین معماری

- هیچ قیمت یا قانون مهمی نباید داخل کد ثابت باشد.
- تمام تنظیمات باید از پنل مدیریت مرکزی قابل کنترل باشد.
- قابلیت‌ها باید ماژولار ساخته شوند تا توسعه‌های بعدی امکان‌پذیر باشد.
